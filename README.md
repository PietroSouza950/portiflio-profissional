# Portfólio de Pietro Souza

Portfólio pessoal de Pietro Souza, estudante de Desenvolvimento de Sistemas no SENAI e desenvolvedor em formação. O site apresenta sua trajetória, tecnologias, estudos e formas de contato.

## Conteúdo

- Início e tecnologias
- Sobre mim e formação
- Projetos e estudos
- Contato por e-mail e GitHub

## Tecnologias

- HTML5 e CSS3
- Bootstrap 5.3.3, carregado por CDN
- Devicon para os ícones das tecnologias
- Google Fonts: DM Sans e Manrope

## Como visualizar

Abra `index.html` no navegador ou execute o projeto com a extensão Live Server do VS Code. É necessária conexão com a internet para carregar Bootstrap, Devicon e as fontes externas.

## Arquivos

- `index.html`: estrutura e conteúdo da página
- `styles.css`: tema, tipografia e estilos personalizados
